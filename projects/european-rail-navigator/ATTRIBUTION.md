# Attribution

The original repository history indicates the following provenance:

| Area | Provenance in the original project |
| --- | --- |
| `Frontend.java` | Benjamin Hsu's assigned frontend implementation |
| `DijkstraGraph.java` | Benjamin Hsu's individual shortest-path implementation, later integrated into the team project |
| `HashTableMap.java` | Benjamin Hsu's individual hash-table implementation, later integrated into the team project |
| integration fixes/build work | Benjamin Hsu |
| `Backend.java` | teammate implementation, later integrated and debugged within the final project |
| interfaces, base graph, HTTP wrapper/template portions | course-provided starter/scaffolding, with integration edits where applicable |

This public-facing version removes the original Git metadata and course submission infrastructure. It is presented to demonstrate the resulting software architecture and the contributions listed above, not to claim sole authorship of every file.
